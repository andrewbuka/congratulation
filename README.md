# Секретное досье — Герои нашего института

Автономное приложение для церемонии награждения. Откройте `index.html` двойным щелчком в Chrome или Edge. Интернет, сервер, установка зависимостей и сборка не требуются.

Встроенный список содержит 20 награждений для 19 человек из документа «ПРОЕКТ Кристина.docx». Вероника Пригодская присутствует дважды, потому что получает две разные награды. Тексты причин награждения взяты из жёлтых выделений этого документа. Суперсилы и три признака каждой карточки взяты из документа «supersily_i_kachestva_20.docx».

## Перед мероприятием

1. На стартовом экране откройте **Редактор** и проверьте список лауреатов и поле **За что награждается**. Этот текст станет главным на раскрытой карточке. Изменения автоматически записываются в LocalStorage. Если карточка ещё не заполнена до конца, сохраняется черновик, который откроется снова после перезагрузки. Кнопка **Сохранить досье** позволяет сохранить заполненную карточку сразу.
2. В редакторе можно изменить порядок стрелками у фамилий, добавить фотографии, сохранить изменения и выгрузить резервную копию через **Экспорт JSON**.
3. Проверьте все досье и показ на том же компьютере, в том же браузере и по тому же пути к `index.html`, который будет использоваться на мероприятии. Данные хранятся в LocalStorage этого браузера. Для переноса на другой компьютер или в другую папку используйте экспорт и импорт JSON.
4. Включите полный экран клавишей **F**. Звук изначально выключен; **M** включает или выключает его.

## Во время церемонии

| Клавиша | Действие |
| --- | --- |
| Пробел | Рассекретить досье; после раскрытия перейти к следующему |
| → | Следующее досье или финальный экран |
| ← | Предыдущее досье |
| R | Снова засекретить текущее досье для повторного рассекречивания |
| F | Полный экран |
| M | Звук |

После раскрытия карточка остаётся на экране до команды ведущего. Уже раскрытое досье при возврате показывается раскрытым; **R** позволяет повторить интригу. Текущий экран, номер досье и уже рассекреченные сотрудники сохраняются в LocalStorage и восстанавливаются после перезагрузки страницы. Тот же шаг записывается в адрес страницы (`#dossier-state=…`), поэтому обновление текущей вкладки работает и тогда, когда браузер ограничивает LocalStorage для локального файла. Если обновить страницу во время сканирования, откроется секретная карточка того же сотрудника. На финальном экране стрелки переключают страницы галереи. Экранные кнопки появляются при движении указателя.

Загрузка фотографии уменьшает и сжимает её в браузере перед сохранением. Если браузер сообщает о нехватке места, уменьшите исходные фотографии или удалите часть из них, затем повторите сохранение. Импорт заменяет текущий список после подтверждения. Кнопка восстановления списка возвращает исходные 20 награждений. При первом обновлении прежние правки пользователей сохраняются; удаляются только неизменённые демонстрационные профили.

Проект состоит только из `index.html`, `style.css`, `script.js` и `laureates.js`. Все ресурсы локальные; до добавления фотографий используются стилизованные силуэты.
