# Секретное досье — Герои нашего института

Автономное приложение для церемонии награждения. Откройте `index.html` двойным щелчком в Chrome или Edge. Интернет, сервер, установка зависимостей и сборка не требуются.

Встроенный список содержит 18 досье и 20 награждений для 19 человек из документа «ПРОЕКТ Кристина.docx». Три благодарности Совета молодых учёных объединены в одно досье с фотографиями Вероники Пригодской, Светланы Леонович и Карины Кантор. Отдельная почётная грамота Вероники Пригодской остаётся самостоятельным досье. Тексты причин награждения взяты из жёлтых выделений документа. Для группового досье придуманы общие суперсила и три признака; у остальных они взяты из документа «supersily_i_kachestva_20.docx».

## Перед мероприятием

1. На стартовом экране откройте **Редактор** и проверьте список лауреатов и поле **За что награждается**. Этот текст станет главным на раскрытой карточке. Изменения автоматически записываются в LocalStorage. Если карточка ещё не заполнена до конца, сохраняется черновик, который откроется снова после перезагрузки. Кнопка **Сохранить досье** позволяет сохранить заполненную карточку сразу.
2. В редакторе можно изменить порядок стрелками у фамилий, заменить фотографии, сохранить изменения и выгрузить резервную копию через **Экспорт JSON**. В групповом досье отдельно редактируются имена, награды, причины награждения и фотографии трёх участниц. Снимки 17 лауреатов уже подключены из папки `assets`; у Винтер и Шкроб пока показаны силуэты. Для двух наград Пригодской используется одна фотография.
3. Проверьте все досье и показ на том же компьютере, в том же браузере и по тому же пути к `index.html`, который будет использоваться на мероприятии. Данные хранятся в LocalStorage этого браузера. Для переноса на другой компьютер или в другую папку используйте экспорт и импорт JSON.
4. Включите полный экран клавишей **F**. Звук изначально выключен; **M** включает или выключает его.

## Во время церемонии

| Клавиша | Действие |
| --- | --- |
| Пробел | Рассекретить досье; после раскрытия перейти к следующему |
| → | Следующее досье или финальный экран |
| ← | Предыдущее досье |
| R | Снова засекретить текущее досье для повторного рассекречивания |
| F | Полный экран |
| M | Звук |

После раскрытия карточка остаётся на экране до команды ведущего. Уже раскрытое досье при возврате показывается раскрытым; **R** позволяет повторить интригу. Текущий экран, номер досье и уже рассекреченные сотрудники сохраняются в LocalStorage и восстанавливаются после перезагрузки страницы. Тот же шаг записывается в адрес страницы (`#dossier-state=…`), поэтому обновление текущей вкладки работает и тогда, когда браузер ограничивает LocalStorage для локального файла. Если обновить страницу во время сканирования, откроется секретная карточка того же сотрудника. На финальном экране стрелки переключают страницы галереи. Экранные кнопки появляются при движении указателя.

Встроенные фотографии загружаются из папки `assets` и не занимают место в LocalStorage. Загруженная через редактор фотография заменяет встроенную для выбранного человека, уменьшается и сохраняется в браузере; удаление фотографии показывает силуэт. Если браузер сообщает о нехватке места, уменьшите загруженные через редактор фотографии или удалите часть из них, затем повторите сохранение. При переносе приложения копируйте папку `assets` вместе с остальными файлами. Импорт заменяет текущий список после подтверждения; старый экспорт с тремя отдельными благодарностями автоматически объединяется в одну карточку. Кнопка восстановления списка возвращает исходные 18 досье. При обновлении уже сохранённого списка три благодарности объединяются с сохранением индивидуальных правок, а ход церемонии переносится на групповое досье.

Приложение состоит из `index.html`, `style.css`, `script.js`, `laureates.js` и папки `assets`. Все ресурсы локальные.
